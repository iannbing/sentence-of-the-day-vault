# Sentence of the Day — Obsidian vault

This folder is auto-synced from a private source repo. New daily
sentences appear here automatically. Drop it into your Obsidian
vault and read along.

## Setup (4 steps, ~2 minutes)

1. **Install Obsidian Git** — Settings → Community Plugins → Browse
   → search "Obsidian Git" → Install → Enable.
2. **Clone this repo into a vault folder** — open the command
   palette (Cmd-P / Ctrl-P), run "Obsidian Git: Clone an existing
   remote repo", paste `https://github.com/iannbing/sentence-of-the-day-vault`, pick a folder name (e.g.,
   "Sentence of the Day").
3. **Enable auto-pull** — Settings → Obsidian Git → "Pull updates on
   startup": ON. "Auto pull interval (minutes)": `60`.
4. **Done.** New sentences arrive in the background.

## Notes

- Public mirror; no authentication needed.
- Don't edit files inside the synced folder — the next pull will
  overwrite your changes. Keep your own notes in a different folder.
- Mobile setup is fragile in v1; desktop is the supported path.

For the full setup walkthrough, see https://sentence-of-the-day.pages.dev/nl/obsidian.
